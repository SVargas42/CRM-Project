Mac port information

Temporary development reset
No database reset was found in the checked-out MainWindowViewModel. Keep it that way: startup must not delete or replace the default workspace.

Paths and key storage
Keep Path.Combine and Environment.SpecialFolder.LocalApplicationData. File.Delete and the exception handling use cross-platform .NET APIs. The macOS implementation is MacKeychainKeyStore. It stores the SQLCipher key as a generic password in the current user's macOS Keychain through the SecItem API; its account is a SHA-256 digest of the canonical database path. Windows continues to use WindowsCredentialKeyStore. Never replace OS-protected keys with plaintext files or hardcoded secrets.

The FoundationChecks project runs a native macOS Keychain round trip and removes its uniquely named temporary test item. It passed on the local Mac when run with local Keychain access.

Local dependencies
Use only an approved local package feed; NuGet.Config has no online sources. On macOS, `python3 scripts/RestoreOffline.py <approved-local-feed> <approved-sha256-manifest>` validates each package hash and uses the local feed as the only restore source. The local cache is artifacts/verified-packages. SQLCipher bundle/provider/native assets are pinned to SQLitePCLRaw.bundle_e_sqlcipher 2.1.11, with Microsoft.Data.Sqlite.Core 10.0.14. That free native SQLCipher bundle is deprecated and needs a maintained approved replacement before production release. Avalonia.BuildServices tasks are excluded and Avalonia.Remote.Protocol runtime assets are excluded. Apply those exclusions to any independently built test project too. No internet restore or download is permitted for this change.

macOS assets and publication
On this Apple Silicon development Mac, a self-contained osx-arm64 publish completed at artifacts/osx-arm64 and scripts/PackageMacApp.py assembled artifacts/HippoCrm.app. The native application opened to its first-run setup screen against an isolated temporary database. The database file and its Keychain key were removed after the check. The app bundle is unsigned and not notarized; use it locally only. Keep WithInterFont() and the bundled Avalonia.Fonts.Inter assets. No remote fonts or assets.

RID-specific offline restores use isolated lock files at artifacts/locks/osx-arm64 and do not change committed cross-platform package lock files. The local RID restore used the approved feed at artifacts/approved-nuget-feed. Publish from this prepared state with:
dotnet build HippoCrm.slnx --configuration Release --no-restore -p:UseSharedCompilation=false -m:1
dotnet publish src/HippoCrm.Desktop/HippoCrm.Desktop.csproj --configuration Release --runtime osx-arm64 --self-contained true --no-restore -p:UseSharedCompilation=false -p:PublishSingleFile=false --output artifacts/osx-arm64
python3 scripts/PackageMacApp.py

For an isolated launch test, set HIPPOCRM_DATABASE_PATH to a disposable database path before invoking artifacts/HippoCrm.app/Contents/MacOS/HippoCrm. A narrowly scoped --delete-macos-smoke-key mode removes only the key for /private/tmp/hippocrm-macos-smoke/crm.db, using the app executable identity that created it. Normal startup remains on the user's Application Support path. Creating a real workspace requires the user to enter their own credentials in the setup screen.

The headless UI test helper now executes each button's bound ICommand after processing bindings; raising ClickEvent alone does not invoke the button's command. This uses managed cross-platform APIs and does not validate native macOS keyboard input.
Debug startup failures emit exception/inner-exception messages and SQLite primary/extended error codes to Debug.WriteLine only. No password or key bytes are printed and no persistent diagnostic log was added. This introduces no platform-specific API.
